What was trained

This experiment follows the paper-first LP-FT path, not the older LoRA path. Updates 1 through 2,000 trained the task heads while the pretrained MantisV2 encoder remained frozen. Updates 2,001 through 10,000 then performed full fine-tuning. No LoRA adapters were active. The experiment tests whether an initialized task head reduces destructive early movement of pretrained features before full fine-tuning.

The NextLeg foundation objective is not the final trading policy. It combines candle reconstruction and leg regression losses. Trend Magic later owns direction; the supervised entry head learns whether to enter or skip a directionally eligible state. Exit and sizing RL are deliberately a later stage and are not part of this run.

Repeat versus resume

The recorded run identities are immutable and already exist. Auditing them means verifying their manifests and hashes, not rerunning commands. A new experiment must copy the TOML files to new versioned names, assign new run.name values, keep allow_overwrite=false, and pin each newly produced parent hash before launching its consumer.

StageSafe restart behavior
Foundation trainRerun the exact training command only when its provenance-checked checkpoint identifies an incomplete run. It resumes from that checkpoint and rejects mismatched source, config, data, or weights.
Validated exportA complete validated export is immutable. Verify its evaluation and parity receipts; do not overwrite it. Retry only after diagnosing an incomplete export under a fresh run identity.
PrepareA complete prepare manifest is immutable. Existing partial output fails closed and must be diagnosed before a new versioned run is created.
EmbedIf no final manifest exists, rerunning the exact command scans and verifies completed atomic pair receipts, then continues from the first missing row. A final manifest makes the stage immutable.
Walk-forwardThis implementation does not resume partial folds. Existing partial output fails closed. Preserve it for diagnosis, then create a new versioned consumer run; never set overwrite merely to bypass provenance.

After success or failure, delete only the exact recorded Pod ID with runpodctl pod delete, then require runpodctl pod list --output=json to return an empty array. The provider termination deadline is a backstop, not a substitute for explicit deletion.

Resume and failure rules

  • Never overwrite an existing run identity and never start a duplicate command against it.
  • Training resumes only from a provenance-checked checkpoint. An atomic temporary checkpoint is not promoted until the write completes.
  • Embedding writes feature, metadata, and pair-receipt shards atomically. Preserve completed pairs after failure and resume only when committed provenance still matches.
  • Do not inspect or rebuild accepted Parquet on a billed GPU. Stage accepted data before GPU provisioning.
  • Terminate every Pod immediately after its verified stage and confirm the provider reports zero active Pods.
  • If a process stops, report the exact error, preserved artifacts, resume condition, and current billed state immediately.

Known caveat and correction

The initial training process emitted CuBLAS and memory-efficient attention nondeterminism warnings because CUBLAS_WORKSPACE_CONFIG was not set before Python started. No result is represented as strictly deterministic. Later CUDA stages set CUBLAS_WORKSPACE_CONFIG=:4096:8; the attention implementation may still remain nondeterministic. This caveat is part of the provenance and any confirmation run must set the variable before training begins.

Full corpus provenance requires the market/, raw/, repairs/, and rolls/ trees. Earlier preflights failed because raw data was omitted and repair/roll directories were flattened. The failure occurred before checkpoints were created, so no trained state was lost. The corrected bundle preserves the expected structure and hashes.

I/O findings

The same-volume run completed in about 32 minutes. Roughly three minutes were spent rehashing the 25.3 GB embedding payload; most remaining time was random feature reads while assembling bounded fold samples. GPU fitting bursts were short, and GPU memory stayed near 1.3 GB. The minimal repeatable path is therefore to attach the existing network volume and budget about 32 minutes for this exact head run.

Do not copy or rewrite the manifest ad hoc. It records absolute artifact paths and hashes. Local ephemeral staging could reduce random-read latency, but it requires a tested manifest-relocation contract that preserves identity; that was not added to this completed run.
