Pipeline

1. Prepare the environment

From the repository root, create the locked environment and run the local gate:

just sync
just gate

The lock pins the resolved Python dependency graph. The gate includes the full synthetic smoke workflow. Production explicitly uses Apple MPS and fails instead of silently falling back to CPU.

2. Verify the pinned upstream model

just verify-upstream

This command downloads or reuses the immutable official checkpoint, verifies its SHA-256 digest, constructs MantisV2 on CPU, and checks the five-channel embedding shape. It does not read market data or start training.

3. Validate the corpus

Mount the external drive so the directory /Volumes/Storage/trading-research/data/FFM_NEXTLEG is available, then run:

just inspect-data mantis-v2/configs/nextleg.toml

The command requires all nine roots at 1, 3, 5, and 15 minute intervals; validates timestamp order, uniqueness, schema, and finite values; and reports legal train, validation, and holdout anchors. It reads data in place and never copies CSVs into the repository.

The verified corpus contains 25,057,097 rows from 2021-07-14 through 2026-07-13. It produces 1,967,568 train anchors, 224,519 validation anchors, and 294,781 isolated holdout anchors. Inspection took approximately 91 seconds on the local host.

4. Prove the pipeline locally

just smoke

The smoke workflow creates deterministic synthetic OHLCV, performs two bounded scratch-model training steps, evaluates validation anchors, writes a resumable checkpoint, exports safetensors, reloads them, and checks output parity.

Then verify the real pinned model, external corpus, and MPS gradient path with a command that is hard-limited to one train batch and one validation batch of 36, giving every configured stream one validation sample:

just probe-mps

5. Start production training

just train mantis-v2/configs/nextleg.toml

The production run verifies the official model revision and weights digest, hashes the 36 data files, builds leak-safe targets, and fine-tunes MantisV2 on Apple MPS for up to 120 epochs. Each epoch uses 200 training batches of 128 samples and 20 validation batches. AdamW uses weight decay 0.05, ten epochs of linear warmup, and cosine learning-rate decay. Training stops after eight epochs without improvement. Context-only statistics standardize both context and future values, and both are clamped to the configured range before differencing so near-constant channels cannot create unbounded candle targets.

Recipe boundary: This is supervised NextLeg regression fine-tuning, not MantisV2 contrastive pretraining. Upstream defines the pretrained model, 512-point interpolation, channel handling, and optimizer schedule. FFM supplies the futures-specific objective, horizons, and bounded sampling regime.

After every epoch, metrics.json records train and validation total loss, candle MSE, leg SmoothL1, learning rate, epoch, and global step. latest.pt supports exact resume; evaluation and export use best.pt, which tracks the lowest validation-total checkpoint. AUC and log loss are produced later by the 3-minute classifier, not this regression stage.

Legacy checkpoint: mantis_ssl_ctr_seq2seq.pt belongs to the original Mantis architecture and cannot warm-start MantisV2. The production run begins from the pinned official MantisV2 weights.

6. Evaluate and export

just validated-export mantis-v2/configs/nextleg.toml

This is the normal release path. It evaluates validation-selected best.pt, records finite metrics plus the checkpoint SHA-256, epoch, global step, completion time, and full provenance, then invokes export. The export function independently fails closed if evaluation is absent or stale, if the checkpoint is not the minimum-loss epoch in durable history, or if config, data, source, lock, or upstream identities differ. It copies the exact validated evaluation into the export bundle and records its SHA-256 in the manifest. Only after the gate passes does it write safetensors, verify every tensor exactly, reload the model, and compare candle and leg outputs within configured tolerances.

The separate just evaluate and just export commands remain available for diagnosis, but direct export cannot bypass the same gate. Normal evaluation uses validation only and refuses a configuration that enables holdout access.

Safety contracts

RiskEnforcement
Cross-stream labelsPivots and targets are built independently for each symbol and interval.
Split leakageContext, candle horizons, and both following legs must remain inside one split.
Future normalizationMean and standard deviation come only from the causal context. Context and future standardized values are both clamped to [-10, 10] before differencing, bounding candle targets to [-20, 20].
Model driftHub revision and safetensors SHA-256 are immutable configuration fields.
Stale resumeConfig, dataset, lock, source, and upstream identities must all match.
Unvalidated exportEvaluation must match the exact best-checkpoint hash, metadata, provenance, and validation-selection history.

Artifacts

Corrected production files are written under /Volumes/Storage/trading-research/artifacts/mantis-foundation-model/mantisv2-nextleg-mps-target-clamp-v2/. The external drive must remain mounted for training and resume. Native checkpoints are for training state; the exported safetensors file is for deployment interoperability.

Training artifacts do not belong in the source Git repository. Keep native pickle checkpoints, optimizer state, validated safetensors, manifests, and evaluations on controlled artifact storage. The upstream license declarations currently conflict, so derived weights must not be uploaded to Hugging Face or otherwise redistributed until the license is resolved. Upload is deliberately absent from this pipeline.

The completed mantisv2-nextleg-mps-target-clamp-v2 artifact is immutable under source commit cc30dcd0a0034140cde0f2ed3b9f35db7f9f3361. It completed evaluation, safetensors parity, and a separate artifact audit before the mandatory gate was introduced. Exact source provenance intentionally prevents later code from reopening that native checkpoint; future training runs use the gate in this guide.

Superseded run: mantisv2-nextleg-mps/ is preserved for diagnosis only. Its 12 completed epochs used unclamped future normalization; a valid one-tick ZN move in a constant-price window produced a target of 15,625. The corrected target changes source and config provenance, so production restarts from the pinned official MantisV2 weights rather than resuming those checkpoints.

Open production decisions

No paid tracking service is configured. Metrics are durable local JSON on the external drive. Hugging Face publication remains blocked pending license resolution. Model quality thresholds and one-time holdout governance remain explicit pre-declared operator decisions; they must not be selected after observing a candidate result.
